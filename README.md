# Real-Time Fraud Decisioning Engine

Streaming fraud-risk service for scoring transaction events with **low-latency features, cost-sensitive classification, and explainable decisions**.

> **Status:** active build. The performance and loss-reduction figures below are targets until reproduced by the included evaluation and load-test suites.

## Goals

- Consume transaction events from Kafka/Redpanda
- Maintain real-time velocity features in Redis
- Score transactions through a FastAPI service
- Train and serve a LightGBM classifier
- Tune decision thresholds against business costs rather than accuracy alone
- Attach top SHAP reason codes to blocked/high-risk transactions
- Monitor feature/model drift with Population Stability Index (PSI)

## Target Resume Metrics

- 36% lower expected fraud loss vs. a rule-based baseline
- 1,500+ transaction events/sec
- <18 ms p99 scoring latency
- Top-3 SHAP reason codes on every blocked transaction

These are **engineering targets, not completed benchmark claims**, until generated by this repository.

## Architecture

```text
Kafka / Redpanda
      |
      v
transaction consumer
      |
      +----> Redis velocity features
      |
      v
FastAPI scoring service
      |
      +----> LightGBM model
      +----> decision threshold
      +----> SHAP explanations
      |
      v
decision event + monitoring
```

## Run Locally

```bash
docker compose up -d
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Health check:

```bash
curl http://localhost:8000/health
```
